VOXEL ENGINE - by Archie Higgins
================================

A custom voxel engine written from scratch in C++ and OpenGL.
Video: https://youtu.be/QCuMJtfSFwY

RUNNING

  Double-click VoxelEngine.exe. Keep it in this folder - it loads the
  shaders/, structures/ and characters/ folders next to it.

  Needs Windows 10/11 (64-bit) and a graphics card supporting OpenGL 4.6
  (most NVIDIA/AMD cards from the last ~8 years, recent Intel).
  Windows may show a SmartScreen warning because the .exe isn't signed:
  click "More info" -> "Run anyway".

CONTROLS

  WASD            Move
  Mouse           Look
  Space           Jump (fly up while flying)
  Left Shift      Fly down
  Left Ctrl       Sprint
  F               Toggle fly mode
  V               First / third person
  Left click      Swing axe (chop trees, dig, hit characters)
  Right click     Place block
  G               Cycle axe damage type (slashing / piercing / bludgeoning)
  L               Toggle 10x time speed
  Esc             Quit

  Fun extras
  1               Shoot an arrow
  2               Launch the test characters into the air (fall damage -> they limp)
  4               Bludgeon the character you're looking at
  J / N           Drop a small / large physics block

THINGS TO TRY
  - Fly up high (F, then Space) to see the terrain stretch to the horizon.
  - Follow a river downhill to where it meets a lake or the sea.
  - Chop through a tree trunk and watch the top fall.
  - Take a leg off one of the characters and watch how it walks.
